Génère un projet Angular 17+ complet pour une plateforme de quizz avec les fonctionnalités suivantes :
- Interface de création et de passage de quizz.
- Partage de quizz via liens et QR codes.
- Gestion des quizz temporaires.
- Internationalisation (i18n) avec ngx-translate.
- Utilisation de Angular Material pour les composants UI.

Structure le projet en modules : core, features, shared.
Fournis les fichiers suivants :
- quizz-creator.component.ts/html/css
- quizz-player.component.ts/html/css
- quizz-share.component.ts/html/css
- auth.service.ts
- translate.service.ts
- environment.ts

Respecte les conventions de nommage et les bonnes pratiques Angular.
