Génère un projet Ionic avec Angular pour une application mobile de quizz avec les fonctionnalités suivantes :
- Réutilisation du code Angular existant.
- Intégration de plugins Capacitor pour scanner QR code, caméra, et stockage sécurisé.
- Adaptation des composants Angular pour Ionic (ex : ion-button).
- Gestion des traductions avec ngx-translate.

Fournis les fichiers suivants :
- qr-scanner.service.ts
- quizz-share.component.ts/html
- capacitor.config.ts
- ionic.config.json
- package.json

Respecte les conventions de nommage et les bonnes pratiques Ionic.
